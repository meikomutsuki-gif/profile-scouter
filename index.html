Profile Scouter

顔認識技術を活用したプロフィール表示システム

About

Profile Scouterは、顔認識技術とデータベースを活用し、 登録された人物のプロフィール情報を表示することを目的とした 大学の研究・開発プロジェクトです。

Project Overview

カメラで撮影した顔画像から特徴量を抽出し、 登録済みの人物情報と照合することで、 対応するプロフィールを表示するシステムを開発しています。

また、本人の同意に基づくXアカウント連携を利用して、 プロフィールや投稿情報から趣味・興味・活動などを取得し、 プロフィールに反映する機能の開発を進めています。

Purpose

本プロジェクトは、大学での学習および技術検証を目的としています。
